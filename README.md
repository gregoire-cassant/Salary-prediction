# Salary Prediction

A machine learning project focused on predicting salaries based on professional and company-related features.

## Overview

This project explores salary prediction using a structured dataset containing information such as job group, years of experience, education level, industry, company size, location, remote work, and certifications.

The project covers the complete data preparation and modeling workflow, from data cleaning and preprocessing to regression model evaluation.

## Features

The dataset includes features such as:

- Job group
- Years of experience
- Education level
- Number of skills
- Industry
- Company size
- Location
- Remote work
- Certifications

The target variable is **salary**.

## Data Preparation

The preprocessing workflow includes:

- Data cleaning
- Handling missing values
- Categorical feature encoding
- Numerical feature preprocessing
- Feature selection and preparation for modeling

## Models

- Linear Regression
- Ridge Regression
- Lasso Regression
- RandomForest
- XGBoost 

The models were trained and evaluated to compare their performance in predicting salary.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Notebook

## Objective

The main objective of this project is to explore a complete machine learning regression workflow, with a focus on data preprocessing and compare different models.
